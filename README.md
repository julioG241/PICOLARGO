# Pico Largo — sitio web

Sitio de una sola página para Pico Largo (manzana deshidratada, Cd. Guerrero, Chihuahua).

- `index.html`, `styles.css`, `script.js`, carpeta `img/`
- Idiomas: español / inglés (botón ES/EN)
- Formulario: envía a **eugenia.gonzalezgomez@udem.edu** vía [Web3Forms](https://web3forms.com) (clave en `index.html`, campo `access_key`).
  Para cambiar el correo, crea una nueva clave en web3forms.com con el correo nuevo y reemplaza `access_key`.

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → elige la rama y la carpeta `/ (root)` → Save.

## Calendario 2027 (Inglés III · proyecto final)
Página aparte en `calendar/index.html` → publicada en `/calendar/`.
Para poner tu nombre y cumpleaños: botón **edit** en la página, o cambia `MY_NAME` y `MY_BIRTHDAY` al inicio del `<script>`.
